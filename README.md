# Скачивание цен и тарифов РФЦ

Скрипт `download_rfc.py` скачивает публичные файлы раздела [Цены и тарифы](https://rfc.kz/ru/single-purchaser-of-electricity/prices-and-rates/) и раскладывает их по папкам `год/месяц/тип`.

Нужен только Python 3, дополнительные пакеты не ставятся.

## Запуск

Из этой папки:

```bash
python3 download_rfc.py --year 2026 --month 05
python3 download_rfc.py --year 2026
python3 download_rfc.py
python3 download_rfc.py --daily
```

- Без аргументов скрипт проходит все месяцы с 2020 по текущий год.
- `--daily` — текущий и прошлый год (для автозапуска раз в сутки).
- Месяц задаётся номером: `01` … `12`.
- Пустой месяц пропускается.
- Уже скачанные файлы повторно не загружаются: учёт в SQLite `data/rfc_files.db`.
- Своя папка для файлов: `--output /путь`. По умолчанию `downloads/`.
- Своя база: `--db /путь/к.db`. По умолчанию `data/rfc_files.db`.

## Автозапуск раз в сутки (macOS)

```bash
chmod +x install_daily.sh
./install_daily.sh
```

Скрипт ставит LaunchAgent `com.rfc.prices.daily`: каждый день в 09:00 запускается `python3 download_rfc.py --daily`.

Логи: `data/daily.log` и `data/daily.err.log`.

```bash
# запустить сейчас
launchctl kickstart -k "gui/$(id -u)/com.rfc.prices.daily"

# отключить
launchctl bootout "gui/$(id -u)/com.rfc.prices.daily"
```

## Куда кладутся файлы

```text
downloads/2026/05/Тариф ВИЭ/....xlsx
downloads/2026/05/Базовые цены/....xlsx
downloads/2026/05/Инвест тариф/....xlsx
downloads/2026/05/Межправ тариф/....xlsx
downloads/2026/05/Расшифровка/....pdf
downloads/2026/05/Примечания/....docx
```

Год и месяц берутся из фильтра страницы, а не из названия файла. В одном месяце бывают и предварительная, и окончательная версии.

Примечания и расшифровки определяются раньше таблиц, даже если в их названии тоже есть «факт» или «базовые цены».

Excel за 2023–2026 называются по-разному, но сходятся в четыре папки:

- **Тариф ВИЭ** — «тариф» и «ВИЭ», «возобновляемых» или «поддержку»
- **Базовые цены** — «базовых цен», включая предварительные значения
- **Инвест тариф** — «инвест», в том числе файлы EkibastuzFerroAlloys
- **Межправ тариф** — «межправ» (такие таблицы есть с 2026 года)

Если таблица не попала ни в один из этих типов, она остаётся в папке **Факт потребления**. Всё остальное — в **Прочее**.

## База данных

В `data/rfc_files.db` хранятся:

- таблица `files` — url, год, месяц, тип, путь, размер, время скачивания;
- таблица `runs` — история запусков (сколько скачано / пропущено / ошибок).

При первом запуске старый `downloads/.manifest.json` переносится в базу (если есть).

Папки `downloads/` и `data/` в git не попадают (см. `.gitignore`).
